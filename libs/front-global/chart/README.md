# chart

This library was generated with [Nx](https://nx.dev).

`lib-chart` accepts Chart.js `data`, `type`, and `options` inputs. Options are
updated alongside data without recreating the chart when its type is unchanged.
Use `type="bar"` with `options.indexAxis = 'y'` for horizontal bars.

## Running unit tests

Run `nx test chart` to execute the unit tests.
